# Alexandre Guitars Archive — V2.2

V2.2 estabelece o primeiro sistema visual compartilhado do Archive.

## Objetivo desta versão

- criar uma linguagem editorial única para o Archive;
- centralizar o CSS em `assets/css/archive.css`;
- padronizar header, footer, tipografia, cores, metadados e navegação;
- transformar as páginas de coleção em páginas editoriais, sem inventar conteúdo;
- manter os quatro Builder's Notes existentes como registros reais;
- preparar a arquitetura para a futura expansão do acervo e do CMS.
